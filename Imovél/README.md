# CONSUMO DE ÁGUA

Projeto desenvolvido em **Python** para classificar o perfil de consumo dos imóveis e emitir alertas educativos de acordo com o tipo de imóvel e o consumo mensal de água.

O programa solicita o **tipo de imóvel** e o **consumo mensal de água em metros cúbicos (m³)**. A partir dessas informações, o sistema classifica o consumo de acordo com as regras definidas para o projeto.

---

##  COMO UTILIZAR O PROGRAMA

Acesse o projeto pelo GitHub:

 [Larissa_Ag7_DS_I](https://github.com/larissapetro/Larissa_Ag7_DS_I)


### 2. No terminal, informe o tipo de imóvel

Digite o **nome ou o número correspondente** ao imóvel:

*  `1` ou `casa`
*  `2` ou `comercial`
*  `3` ou `apartamento`

### 3. Informe o consumo

Digite o valor numérico correspondente ao consumo mensal de água em **m³**.

O programa analisará as informações e exibirá uma mensagem de acordo com o perfil de consumo.

---

##  CLASSIFICAÇÃO DO CONSUMO

- Comercial - Qualquer valor = Tarifa comercial
- Apartamento - Menor que 10m³ = Consumo econômico
- Casa/Apartamento - ate 25m³ = consumo moderado
- Casa/Apartamento - acima de 25m³ = consumo excessivo
